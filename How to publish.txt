TAG TRAUMA HANDBOOK - HOW TO PUBLISH AND UPDATE
================================================

What is in this download
------------------------
handbook/   The finished web app. This is the only folder you upload.
source/     The editable text of each guideline and the scripts that
            rebuild the handbook folder. Only needed to change content.

The app is plain web files. It does not use Claude or any other
service, and nobody needs an account to open it.


1. Put it online (about 5 minutes, free)
----------------------------------------
Any web host for static files will work. The simplest is Netlify:

  a. Create a free account at https://www.netlify.com and log in.
  b. Go to https://app.netlify.com/drop
  c. Drag the "handbook" folder onto the page.
  d. Netlify gives you a web address. You can change it to something
     memorable in the project's settings.

Alternatives that work the same way: GitHub Pages, Cloudflare Pages.

Anyone who has the address can open the handbook. It asks search
engines not to list it, but treat the address as public.


2. Share it
-----------
Send the address, or put it in a QR code on the resus bays and
airway trolley.

To install it as an app icon:
  iPhone:   open the address in Safari, tap Share, then
            "Add to Home Screen".
  Android:  open it in Chrome, tap the menu, then "Add to Home
            screen" or "Install app".

After the first visit it works with no signal.


3. Update it
------------
  a. Get the new "handbook" folder (see section 4).
  b. In Netlify, open the project, go to "Deploys", and drag the new
     folder onto the drop area at the bottom of that page.
  c. Phones pick it up the next time the app is opened with signal.
     People see a "New version ready. Tap to update" button.

The date of the installed version is shown at the bottom of the
home page ("Handbook updated ...").


4. Change the content (needs someone comfortable with a command line)
---------------------------------------------------------------------
Each guideline is a text file in source/content. Figures are in
source/site/fig.

  One-off setup:   install Python 3, then run
                   pip install markdown beautifulsoup4
  After editing:   in the source folder run
                   python3 build.py
                   python3 package.py
  Result:          a fresh folder at source/app/handbook - upload
                   that one as in section 3.

When a guideline is reissued, update its text file and the version
line at the top of that file, then rebuild.
