## Definition

Videolaryngoscopy is an easily available tool for management of the anticipated difficult airway. The most commonly used system at RLH is the C-Mac, although the Airtraq system is also available.

## C-Mac

The C-Mac system uses a disposable, single-use plastic blade over a fiberoptic endoscope. Blades available include the Macintosh 3, 4 and ‘D Blade’ which is a hyperangulated blade. These systems are available throughout ED, Theatres and ITU.

## Tips and tricks

- A standard Macintosh 4 blade has the benefits of a familiar laryngoscopy technique and a direct view if blood / debris covers the camera.
- If struggling to get tube off stylet, withdraw the blade to a ‘less optimal' view which improves the angle of tube delivery.
- If using a D Blade, use a pre-formed stylet / Frova bougie to match curve of blade - see picture below.
- Battery life is approximately 3.5hours - if it has been appropriately stored and charged, it doesn’t need to be plugged in once in theatre - this can just add to the tangle of wires!
- If the light source is not sufficiently inserted and correctly seated into the plastic blade, significant glare can occur obscuring the view - this is particularly problematic when using the ‘D’ blade.
