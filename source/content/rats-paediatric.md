## Paediatric CODE RED

The principles are broadly similar to an adult CODE RED.

There are weight-based guidelines for blood products and suggested maximum volumes (available on Box app).

| | RBCs | FFP / Octaplas | Platelets | Cryo | TXA |
|---|---|---|---|---|---|
| **< 30kg** | 10 - 20 mL/kg | 15mL/kg | 15mL/kg | 10mL/kg | 15mg/kg (max 1gram) |

ROTEM can be used for Paediatric patients however, the algorithm differs slightly.

## Key Formulae

**Weight**

- Age 1 - 5yo = (Age x 2) + 8
- Age 6 - 12yo = (Age x 3) + 7

**ETT size and length**

- Uncuffed ETT = (Age / 4) + 4.5
- Cuffed ETT ID = (Age / 4) + 4
- ETT Length = (Age / 2) + 12

## Key Drug Dosages

- Suxamethonium = 1 - 2mg/kg
- Rocuronium (RSI) = 1mg/kg
- Propofol = 1 - 2mg/kg
- Ketamine = 1 - 2mg/kg
- Fentanyl = 1mcg/kg
- Atropine = 20mcg/kg (minimum 100mcg)
- Adrenaline = 0.1mL/kg of 1:10,000

The CATS website is a valuable source of information for paediatric drug dosages including the infusions of vasopressors and maintenance of anaesthesia ([www.cats.nhs.uk](https://cats.nhs.uk/)).
