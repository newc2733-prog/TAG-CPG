## Identify

1. **Systolic blood pressure < 90mmHg AND**
2. Suspected active haemorrhage

Nominate team member as **CODE RED Communication Lead**

- Call Haematology Lab (Ext 61108) to request CODE RED PACK A or B
- Collect 6x RBCs from emergency fridge
- O negative (females) / O positive (males)
- Other products to be collected by Porter / HCA from Transfusion Lab
- Ensure being sent to correct area (Resus vs IR vs Theatres)
- FFP can only be returned to the fridge if out for <30min
- Strongly consider putting FFP straight into theatre blood fridge if not being used immediately
- Track transfusion on Transfusion Board in theatre
- (nominate one person responsible for this)

## Initial resuscitation

- 6 units RBC/ 6 Units FFP (PACK A)
- Baseline bloods - ABG / G + S / ROTEM / FBC
- 2g TXA IV push - check pre-hospital + ED Resus treatments.

## Ongoing bleeding?

- 6units RBC / 6 units FFP / 2 Cryoprecipitate / 1 pool Platelets (PACK B).
- Porter collects - **order EARLY**
- BASTE (**see [BASTE](#rats-baste)**)
- Transfusion guided by ROTEM (**see [Code Red ROTEM Algorithm](#rotem-algorithm)**)

## Bleeding controlled?

- Step down CODE RED - inform Haematology Lab (Ext 61117 / Ext 60344)
- Return unused products.

## Drugs

Drugs for RSI, haemostasis, blood pressure support and electrolyte management should be drawn up as ASAP - transfer to theatre may be rapid.

**Note** Concentration of Actrapid - 15IU and 50IU in 50mL are both routinely used. Prepare as opposite for CODE RED. (see [Code Red CPG](#code-red.s3))
