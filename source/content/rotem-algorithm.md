## Code Red Trauma

| Stage | |
|---|---|
| **Code Red activation** | • Pack A - 6x PRBC + 6x FFP<br>• Ensure TxA 2g administered (bolus) |
| **Ongoing bleeding** | • Maintain TEMP>35°C<br>• Maintain ionised CALCIUM>1mmol/l |
| **DCS** | • Move to Theatres or Interventional Radiology<br>• Consider Cell Salvage<br>• Continue empiric transfusion (PRBC:FFP in 1:1 Ratio) |

## ROTEM Algorithm

| Step | |
|---|---|
| **1. Thrombin generation** | If EXTEM CT>80s<br>**GIVE 4x UNITS FFP** |
| **2. Fibrinogen** | If FIBTEM A5<10mm<br>**GIVE 2x POOLS CRYOPRECIPITATE** |
| **3. Platelets** | If (EXTEM A5 – FIBTEM A5) = <30mm<br>**GIVE 1x POOL PLATELETS** |
| **4. Fibrinolysis** | If EXTEM LI30<85%<br>**GIVE 1g TXA BOLUS** |

> ROTEM repeatable as soon as **15min** after blood products to assess treatment response and to further guide therapy
