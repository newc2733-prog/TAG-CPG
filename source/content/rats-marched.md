## Preparing the Theatre for Code Red

Preparation for a CODE RED is something that begins from the moment the bleep goes out. The coordinated, simultaneous activity of independent team members will usually occur with little to no input. However, there will *always* be value in double-checking the theatre environment is optimised and the equipment is available for immediate use - checklists are available to assist with this. In addition, the theatre team have a ‘default setup’ for instruments etc for laparotomy / thoracotomy / craniotomy. MARCHED is an acronym that may be helpful in remembering all potential steps.

## M A R C H E D

| | |
|---|---|
| **M**ajor Haemorrhage | CODE RED trolley with balanced transfusion board in theatre<br>MAC trauma line prepared<br>RIC (Rapid Infusion Catheter) prepared (Theatre 8 CODE RED drawer)<br>Ultrasound and sterile probe covers available |
| **A**irway | Airway trolley prepared for RSI<br>C-Mac system available (especially if blunt trauma) |
| **R**EBOA | Refer to **[REBOA and Monitor Setup](#rats-reboa)**<br>Prepare to transduce both REBOA sheath and catheter |
| **C**irculation | Cardiac arrest trolley available (PEA most common rhythm in trauma)<br>Belmont Rapid infuser plus consumables including 500mL 0.9% NaCl - do not need to prime, ED will also prepare. Consider using Belmont bucket - see **[Belmont Rapid Infusion Device](#rats-belmont)**<br>Arterial line kits x 2 (left and right) - bilateral, concurrent attempts |
| **C**irculation | Unlikely a CVP transducer will be needed - prepare a single transducer for simplicity, this can also be pre-zeroed to save time |
| **H**ypothermia | Refer to **[Warming Kit (Inditherm)](#rats-warming)**<br>Increase theatre temperature to 25<sup>O</sup>C / maximum<br>Prepare Inditherm controller and have mattress available - patient should arrive from ED on mattress<br>Have under-body Bairhugger on theatre table + surgical access Bairhugger blanket available<br>Consider gamgee / inco-pads to cover head / exposed limbs |
| **E**xpect | Prepare for multiple ABG and ROTEM samples including a baseline sample - 10mL / 5mL syringes, ABG syringes, blue vacutainer and blunt needles<br>Blue vacutainers **must** be filled to 2.7mL line - incorrect volume of blood will invalidate results of ROTEM<br>Extra ODPs required? Consider need for dedicated Airway / Left hand / Right hand / Belmont ODPs |
| **D**rugs | Prepare as **[Code Red: Activation](#rats-code-red-activation)**<br>General anaesthetic - Fentanyl 500mcg (50mcg/mL), induction agent (Ketamine), muscle relaxant (Rocuronium)<br>Electrolyte correction - 10mL calcium chloride, insulin / glucose to correct hyperkalaemia (note high dose concentration used)<br>TXA 2g (within first 3 hours), 1g (every whole body transfusion) |
